## Implement

Create repository-root `math-tool.ps1` with:

- A parameter named `N` accepting non-negative integer input.
- A pure `Get-Fibonacci` function that returns the numeric Fibonacci value and emits no other pipeline output.
- Direct script execution that invokes the function and writes exactly `Fibonacci(N) = value` as its single stdout result line.

Create repository-root `math-tool.Tests.ps1` with:

- Dot-sourced unit coverage of `Get-Fibonacci`.
- Isolated child-`pwsh` process coverage of direct CLI behavior, so the CLI assertions do not accidentally pass because the test process already loaded the function.
- Cases for `N=0`, `N=1`, and a small representative value such as `N=5`.

Keep the implementation objective and small. Follow existing repository conventions and instructions.

## Completion gates

- `Get-Fibonacci 0`, `Get-Fibonacci 1`, and `Get-Fibonacci 5` return numeric values `0`, `1`, and `5`, respectively, without incidental output.
- Isolated direct invocations for the same cases exit zero and produce exactly one stdout line: `Fibonacci(0) = 0`, `Fibonacci(1) = 1`, and `Fibonacci(5) = 5`, respectively.
- CLI checks discriminate exact formatting: no labels other than `Fibonacci`, no extra whitespace-only or diagnostic lines, and no in-process shortcut in place of a child `pwsh` invocation.
